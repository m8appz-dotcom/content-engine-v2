# Verification and limits

The five-demo implementation was exercised through the Codex browser MCP in hidden tabs on X. The approved screens remain the baseline. No desktop focus or native keyboard input was used.

Authored workspace checks:

- Choose one of three English story examples.
- Edit its script, compare a claim with the source, and approve the current revision.
- Export the approved storyboard. Editing the script resets approval.

Shared checks: English visible/accessible content; desktop, narrow and intermediate compositions; local persistence; workspace export, compatible restore, invalid-file rejection and undo through the shared recovery UI. Product-specific JSON, CSV and ZIP files were downloaded and read independently. The locked Longform contract's SHA-256 matches its canonical UTF-8 script; the Toolkit ZIP passes a standard ZIP reader and preserves its selected originals.

Corrections during browser review included an editor/navigation overlap in Longform, the narrow JEV status selector, preservation of incomplete JEV review notes and placement of M8 replay controls. Original source images were not modified.

Automated checks reject unsigned workspace access, foreign-origin mutations, invalid registration, replayed challenges and unknown credentials. Real holder registration/login/recovery remains pending. Full accessibility certification, physical mobile-device testing, microphone/audio acceptance and finished-film acceptance are not claimed. Connected engine checks below have their stated scope.

Scope limit: Storyboard planning is connected to the repository engine. No model generation, production database integration, finished-video rendering or publication is performed.

## Connected engine update

Calls the actual ScriptCandidate/Evidence schemas, claim-reference verifier, production planner and storyboard builder. The current English draft becomes the timed storyboard. This is deterministic planning; it does not make a model call, certify factual accuracy, approve a draft or render a finished video.

Gateway negative tests cover origin, protected actions, session ownership, unsupported input, invalid service credentials, safe errors and path containment. Physical holder passkey acceptance remains pending; it is never inferred from these tests.

Runtime acceptance: The native schemas and planner produced the current draft’s timed storyboard; the browser opened and downloaded that real result.
