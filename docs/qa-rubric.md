# QA Rubric

Scores are 0–5 for evidence_support, rights_safety, privacy_safety, sme_clarity, hook_strength, narrative_coherence, visual_proof, caption_readability, audio_quality, and pace.

`publish_ready` requires QA pass, evidence_support/rights_safety/privacy_safety = 5, no category below 4, no blocking issues, and explicit publish approval.
